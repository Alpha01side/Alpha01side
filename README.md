# Hello

I work on the practical side of e-commerce: SEO, WordPress and WooCommerce stores, print-on-demand catalogues, and the documentation that keeps all of it consistent.

I am not a software developer and I do not present myself as one here. What I publish on GitHub is written documentation: checklists, audit steps, templates and notes taken from real store work. Git is simply the best place I have found to keep that documentation versioned and public instead of scattered across notes apps.

## What I work on

- Technical and on-page SEO for WooCommerce and WordPress stores
- Product and category content written for buyers first and search engines second
- Print-on-demand catalogues: product data quality, thin content and duplicate variations
- Website optimization and page speed from a store owner's point of view
- Technical documentation and repeatable processes for the above

## What I am learning right now

- Structured data beyond the basics, especially variable products and breadcrumbs
- Reading Search Console and server-side data properly instead of relying on plugin dashboards
- Markdown and Git workflows so my working notes are versioned and reviewable
- Measuring the effect of a single change rather than shipping ten at once

## Repositories

- **[woocommerce-seo-optimization](https://github.com/Alpha01side/woocommerce-seo-optimization)** — checklists, guides, templates and structured data notes for WooCommerce and WordPress stores.

More will follow when I have material that is tested enough to be worth publishing. I would rather have three useful repositories than twenty empty ones.

## How I write documentation

- Original wording only. No copied articles, no scraped content, no reworded competitor posts.
- Where something comes from official Google, WordPress or WooCommerce documentation, I link to the source instead of reproducing it.
- No invented statistics and no guaranteed results. If I have not tested something, I say so.
- Corrections are welcome. Open an issue and tell me what you saw on your own store.
